# Contribution Guidelines

Thank you for your help. Please follow these rules so that the list stays useful.

## What to add

- Tools, papers, datasets and resources about **AI and cyber deception**: AI used for deception, or deception used against AI attackers and AI systems.
- Foundational deception tools only if they are widely used or are a common base for AI work.

## Rules

- Add one entry per pull request, or explain why several entries belong together.
- Put the entry in the correct section. For papers, add it at a logical place in the subsection.
- Use this format:
  `- [Name](https://link) - Short description that ends with a period.`
- For papers, use: `- [Title](link) - First author et al., Venue, Year. Optional short note.`
- Keep the description short and factual. Do not use marketing words.
- Check that the link works. Use the canonical URL (for papers, prefer the arXiv abstract page or the publisher page).
- Mark projects that are archived or no longer maintained with *Archived.*
- Do not add a project that has no documentation or that you cannot verify.
- Commercial products go in [Commercial Platforms](README.md#commercial-platforms) only, in alphabetical order.

## Removal

Open an issue or a pull request if a link is dead, a project is abandoned, or an entry is wrong.
